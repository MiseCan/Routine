# Routine

通过 AI 对话，把目标拆成每天能执行的任务。Android 手机独立运行，直接连接 DeepSeek，无需电脑或 USB。

[下载与历史版本](https://github.com/MiseCan/Routine/releases)

当前版本为 **Routine 0.16.3**，应用 ID 和源码命名空间均为 `com.routine`，签名相同时可覆盖升级 0.15.0。历史旧包名应用的计划、聊天和 API 密钥不会自动迁入。

支持 Android 12（API 31）及以上。目前发布的是**调试签名的内测 APK**，尚未制作正式签名构建。

## 功能

- **单会话规划**：默认创建新计划；点击聊天顶部切换为编辑已有计划。AI 将顶部计划名概括为七字以内的完整短语，详情保留全名。会话可确认清空。
- **补全信息**：从对话提取目标、交付物、截止日期和进度，缺失时给出与任务相关的推荐选项。第三轮询问后可点击“生成计划”，也可继续细聊。
- **真正的每日任务**：计划先在聊天预览，确认后加入看板。长期重复内容用日期范围或星期规则表达，再由手机展开为独立的每日任务；最长三年、最多 5000 项，可逐天编辑。
- **看板与记录**：查看今天、明天、待补做及所有计划；编辑或确认删除计划。完成任务必须填写本次完成内容，撤销完成保留历史记录。
- **对话操作应用**：查询任务和完成记录，管理计划与每日任务，调整提醒、外观、模型和个性化要求，打开页面或附件选择器。修改先展示具体对象与变更，确认时重新检查目标 ID 和数据，避免旧预览覆盖新变化。
- **发送资料**：支持图片、PDF、DOCX 和文本文件。图片及 PDF 需要所选模型支持图片；DOCX 读取正文。每条最多 6 个附件，每个不超过 12 MB，PDF 最多 12 页。
- **安静提醒**：每天 8:00～23:00 每小时提醒今日未完成任务，默认无声音、无振动、不弹窗，同一条通知更新；没有待办或全部完成时不发送。
- **Material 3 Expressive**：支持系统动态取色、深浅主题和统一动效，设置使用官方 Material Symbols Rounded 图标。

工作日、休息日和节假日规则采用中国大陆已收录的 2026 年调休日历；其他年份或个人班表先确认具体日期或星期规则。AI 查询长列表时按需分页，不会把未读取的部分视为空任务。

## 开始使用

1. 安装 APK，打开看板右上角的设置。
2. 填写自己的 DeepSeek API 密钥，点击“保存密钥并获取模型”，再从接口返回的模型中选择。
3. 可添加个性化提示词。内置规则不可修改，在“设置 → 关于”查看；个性化要求独立发送，输出仍须通过软件校验。
4. 在 AI 聊天中描述目标，补齐信息并确认每日计划。
5. 允许通知后接收提醒。系统省电可能延迟发送，如需整点提醒，可在设置中允许可选的准点提醒权限。

密钥输入、系统授权和文件选择由用户在相应界面完成，AI 不读取或写入密钥。

## 升级说明

**从 0.11.x 或更早版本首次升级到 0.12.0，会一次性清除旧聊天、附件和未保存草稿，不迁移多会话数据。看板计划、完成记录和全局设置保留。** 后续启动不会重复清空。

## 数据与网络

任务、聊天和个性化要求保存在本机；API 密钥使用 Android Keystore 加密保存。发送消息时，相关对话、任务、设备时间和附件内容会通过 HTTPS 交给 DeepSeek 处理。模型列表来自 DeepSeek 接口。

提醒在手机本地运行，不联网、不调用 AI。没有云同步。仓库不包含实际 API 密钥、服务配置、手机截图或运行日志。`server/` 是早期电脑服务版本的历史源码，当前 Android 应用不依赖它。

## 构建

需要 JDK 21+、Android SDK 37；项目使用 Gradle 9.8.1、Android Gradle Plugin 9.4.1、Compose 编译器插件 2.4.21、Material 3 1.5.0-beta01、Miuix Nav 0.9.4。配置 `ANDROID_HOME`，或在本机 `local.properties` 中设置 SDK 路径。

macOS / Linux：

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Windows：

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

全量包输出到 `app/build/outputs/apk/debug/app-debug.apk`。使用 `:app:assemblePhone` 构建 R8 裁剪包，输出到 `app/build/outputs/apk/phone/app-phone.apk`。Windows 上运行 `./build.ps1` 会构建全量包，并向已连接的手机安装 R8 裁剪包。只需构建全量包时使用 `./build.ps1 -NoInstall`。
