# Material Symbols

The settings symbol is Google's official **Material Symbols Rounded** `settings`,
regular weight, unfilled, 24px optical size. The SVG path is preserved in
`app/src/main/java/com/routine/MaterialSymbols.kt`; its negative-Y SVG viewBox
is translated into the Compose vector viewport.

Source: [Google material-design-icons / settings_24px.svg](https://github.com/google/material-design-icons/blob/master/symbols/web/settings/materialsymbolsrounded/settings_24px.svg)

## Routine launcher icon

The original Routine “daylight + completion” mark is maintained in `design/launcher-icon.svg`. Android adaptive foreground/background and Android 13 monochrome layers use the same vector geometry. See [design notes](design/ICON_DESIGN.md).
